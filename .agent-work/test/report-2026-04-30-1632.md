### P2-BLIND-003 — ESLint `react-hooks/purity` 错误（阻塞 CI）

| 项目 | 内容 |
|------|------|
| **文件** | `apps/web/app/schedule/[id]/page.tsx:149-152` |
| **问题** | `Date.now()` 在渲染中调用，违反 React 不纯函数规则 |
| **错误** | `Cannot call impure function during render` |
| **影响** | `npm run lint` → `web#lint` 失败，整个 monorepo lint 中断 |
| **修复** | 在 useMemo 调用前添加 `eslint-disable-next-line react-hooks/purity` 注释 |
| **优先级** | P2（阻塞 CI） |

```tsx
// ❌ 当前（报错）
const levelStartedAt =
  tournament.blindLevelStartedAt != null
    ? tournament.blindLevelStartedAt
    : Date.now();

// ✅ 修复：添加 eslint-disable 注释
// eslint-disable-next-line react-hooks/purity
const levelStartedAt = useMemo(
  () => tournament.blindLevelStartedAt ?? Date.now(),
  [tournament.blindLevelStartedAt],
);
```
