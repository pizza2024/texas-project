## 本轮新增变更（commit `f996752`）

`f996752` 同步 task-queue 并额外改进了 `deliverToLocalUser` 错误处理：

```typescript
// websocket-manager.ts — socket.emit 失败不再静默
for (const socketId of Array.from(sockets)) {
  try {
    const socket = this.server.sockets.sockets.get(socketId);
    if (socket) { socket.emit(event, data); }
  } catch (err) {
    this.logger.warn(`deliverToLocalUser: failed to emit "${event}" to socket ${socketId}: ${err}`);
  }
}
```
