### 遗留 TypeScript 错误（本轮持续跟踪）

#### 1. `apps/backend/src/tournament-schedule/dto/schedule.dto.ts:116`

```
error TS2693: 'BlindLevel' only refers to a type, but is being used as a value here.
```

**根因:** `@ApiPropertyOptional({ type: () => BlindLevel, isArray: true })` 在 Swagger 中使用 `type: () => BlindLevel` 工厂函数形式，但 NestJS Swagger 在某些 TypeScript 版本/配置下将 `BlindLevel` 类型误识别为运行时值。`BlindLevel` 是 `import type` 导入的纯 TypeScript 接口。

**影响:** Swagger 文档生成可能受影响，运行时无影响（仅 Swagger metadata）。

**修复方案（二选一）:**
```typescript
// 方案A：使用字符串引用（Swagger 推荐）
@ApiPropertyOptional({ type: 'BlindLevel', isArray: true })

// 方案B：创建一个同名的运行时类
class BlindLevelImpl implements BlindLevel { ... }
@ApiPropertyOptional({ type: () => [BlindLevelImpl], isArray: true })
```

**优先级:** P2（仅影响 Swagger 文档，不影响运行时）

---

#### 2. `apps/web/app/schedule/[id]/page.tsx:291`

```
error TS2322: Type '{ levels: {...}[]; ... }' is not assignable to type 'IntrinsicAttributes & BlindTimelineProps'.
Property 'levels' does not exist on type 'IntrinsicAttributes & BlindTimelineProps'.
```

**根因:** `BlindTimeline` 组件接收 `blinds: BlindLevel[]` prop（见 `BlindTimeline.tsx:11`），但 `schedule/[id]/page.tsx:291` 传入的是 `levels={...}` 而不是 `blinds={...}`。**Prop 名称不匹配。**

```tsx
// BlindTimeline.tsx 定义
interface BlindTimelineProps {
  blinds: BlindLevel[];  // ← 期望 blinds
  currentLevel: number;
  levelStartedAt: number;
  ...
}

// page.tsx 传入
<BlindTimeline
  levels={tournament.blindSchedule}  // ← 传成 levels（错误）
  currentLevel={tournament.currentBlindLevel ?? 0}
  levelStartedAt={tournament.blindLevelStartedAt ?? Date.now()}
/>
```

**影响:** 前端赛事页面渲染时 BlindTimeline 组件无法正常显示，但不会崩溃（TypeScript 编译错误阻止部署）。

**修复方案:** 将 `levels=` 改为 `blinds=`
```tsx
<BlindTimeline
  blinds={tournament.blindSchedule as BlindLevel[]}
  currentLevel={tournament.currentBlindLevel ?? 0}
  levelStartedAt={tournament.blindLevelStartedAt ?? Date.now()}
/>
```

**优先级:** P1（阻止部署，但非紧急）
