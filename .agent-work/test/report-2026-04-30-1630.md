## 代码审查

### 🆕 P2-BLIND-003 — ESLint `react-hooks/purity` 错误（新增）

**文件:** `apps/web/app/schedule/[id]/page.tsx:293`

```tsx
levelStartedAt={tournament.blindLevelStartedAt ?? Date.now()}
```

**问题:** `Date.now()` 是不纯函数（impure），在组件渲染期间调用违反 React 规则。渲染可能在任意时间重复，导致 `Date.now()` 每次返回不同值，产生不稳定结果。

**影响:** ESLint 报错 `web#lint` 失败，整个 monorepo lint 失败。

**修复方案:**
```tsx
// 方案A（推荐）: 在渲染前计算默认值
const levelStartedAt = tournament.blindLevelStartedAt ?? Date.now();
<BlindTimeline levelStartedAt={levelStartedAt} ... />

// 方案B: BlindTimeline 组件内部处理
// levelStartedAt prop 类型改为非必需的，由组件内部 useEffect 初始化
```

**优先级:** P2（阻塞 monorepo CI）
