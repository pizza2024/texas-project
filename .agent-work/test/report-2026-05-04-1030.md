**P2-SCHEDULE-001: TournamentScheduleController 全部端点无 AdminGuard**

| 问题 | 详情 |
|------|------|
| **文件** | `apps/backend/src/tournament-schedule/tournament-schedule.controller.ts` |
| **影响端点** | `POST /tournament-schedule/:id/start`（启动赛事）、`POST /tournament-schedule/:id/complete`（完成赛事）、`DELETE /tournament-schedule/:id`（取消赛事）、`POST /tournament-schedule/:id/reminder`（发送提醒）|
| **风险** | 任何认证用户可操控所有赛事计划（启动/取消他人创建的赛事、发送虚假提醒） |
| **紧迫度** | P2 — 管理端功能，非公开端点 |
| **修复方案** | 在 controller 类或各 endpoint 添加 `@UseGuards(AdminGuard)`；或在 `startTournament`/`completeTournament`/`cancelSchedule`/`emitReminder` 上加 `@Roles('ADMIN', 'SUPER_ADMIN')` |

```typescript
// 当前：完全开放
@Post(':id/start')
async startTournament(@Param('id') id: string) { ... }

// 应添加（参考 withdraw.controller.ts:128）:
// @UseGuards(AdminGuard)
```
