### P0-WS-001 详细分析

**当前代码顺序（app.gateway.ts）:**
```
324:  this.clearPendingDisconnect(payload.sub);        ← 清理旧断开计时器
343–361: evict 循环 — 查找并断开同用户旧 socket
364:  await client.join(`user:${payload.sub}`);        ← 新 socket 加入房间
366–372: userSockets.set / .add — 新 socket 加入索引  ← 太晚！
```

**问题：** 在 366–372 行之前，若 `other.disconnect()` 触发 `handleDisconnect` → `userSockets.delete(other.id)`，而此时新 socket 尚未在 `userSockets` 中（367–372 尚未执行），`hasOtherActiveSocket` 检查会错误返回 `false`。
