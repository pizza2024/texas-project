**文件**: `src/websocket/app.gateway.ts`
**问题**: `handleConnection` 中 `clearPendingDisconnect(payload.sub)` 在重连检查之前调用，导致重连时错误地清除待处理断开连接状态，破坏跨实例重连逻辑。

```diff
- // 重连检查

+ clearPendingDisconnect(payload.sub)
```

**文件**: `src/room/room.service.ts`

### P1-MATCH-001 — `handleQuickMatch` 无用户级并发锁
**文件**: `src/websocket/game.handler.ts`
**问题**: `handleQuickMatch`（第 442 行）无 `withUserLock` 保护，同一用户并发请求可能导致快速匹配房间重复创建或竞争条件。
**修复**: 将 `findOrCreateMatchmakingRoom` 及后续逻辑包裹在 `gateway.withUserLock(userId, async () => {...})` 中，并在锁内重新检查用户当前房间状态（防止 TOCTOU 竞争）。
```ts
return gateway.withUserLock(userId, async () => {
  const currentRoomId2 = await gateway.tableManager.getUserCurrentRoomId(userId);
  if (currentRoomId2) {
    client.emit('match_error', { message: 'already_in_room', roomId: currentRoomId2 });
    return;
  }
  // ... findOrCreateMatchmakingRoom, recordPlayerJoined, match_found
});
```

### P1-WS-002 — `deliverToLocalUser` socket.emit 无保护
**文件**: `src/websocket/websocket-manager.ts`
**问题**: `deliverToLocalUser` 中若 socket 已断开但仍存在于 `localSockets` Map 中，`socket.emit()` 会抛出未捕获异常，导致其他待发送消息也被丢弃。
**修复**: 在 `for` 循环内对每个 `socket.emit()` 添加 try-catch，单个 socket 失败不影响其他接收者，失败时 logger.warn 记录。

### P1-REDIS-001 — `notifyFriendsOfStatusChange` 友元状态通知无防护
**文件**: `src/websocket/app.gateway.ts`
**问题**: `notifyFriendsOfStatusChange` 中的 `emitToUser` 调用无 try-catch，若 `wsManager.emitToUser` 本身抛出异常会导致整个函数失败，影响其他好友通知。
**修复**: 将每个好友的通知逻辑包裹在异步 IIFE 中，对 `emitToUser` 调用进行 try-catch 保护，异常时 logger.warn 记录并继续处理其他好友。
