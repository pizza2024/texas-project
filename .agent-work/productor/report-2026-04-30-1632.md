```bash
60c6ae6 fix(tournament): BlindTimeline key={blind.level}→key={index} — React key warning
```

### P2-BLIND-003 — 新发现（阻塞 CI）

Test r72 新增一个 ESLint 错误，阻塞 CI：

| 项目 | 内容 |
|------|------|
| **文件** | `apps/web/app/schedule/[id]/page.tsx:293` |
| **问题** | `Date.now()` 在 JSX 渲染中调用，违反 React 不纯函数规则 |
| **错误** | `react-hooks/purity: Cannot call impure function during render` |
| **影响** | `npm run lint` → `web#lint` 失败，整个 monorepo lint 中断 |
| **优先级** | P2（阻塞 CI） |

```tsx
// ❌ 当前（报错）
levelStartedAt={tournament.blindLevelStartedAt ?? Date.now()}

// ✅ 修复方向：将变量提前到渲染前计算
const levelStartedAt = tournament.blindLevelStartedAt ?? Date.now();
<BlindTimeline levelStartedAt={levelStartedAt} ... />
```

**建议 Coding 修复:** 将 `Date.now()` 调用移出 JSX，在组件 body 顶部或 useMemo 中计算。

## 竞品调研 — Battle Pass / Season Pass 模式

本轮聚焦竞品 ** monetization model ** 趋势，特别关注 **Battle Pass / Season Pass** 机制：

### Battle Pass / Season Pass — 行业现状

| 平台 | 产品名 | 定价 | 周期 | 内容 |
|------|--------|------|------|------|
| **GGPoker** | Mission System / 赛季任务 | 免费+付费赛季券 | 赛季制 | 每日/每周任务，奖励筹码/皮肤/门票 |
| **WSOP** | Ring Game Missions | 免费附带 | 持续 | 达成手数/盈亏目标获奖励 |
| **888poker** | 888poker Club | 订阅制 VIP | 月度 | 返还 rake，独家锦标赛资格 |
| **GGPoker** | Diamond Dragon Club | 月订阅 $25~$500 | 月度 | 阶梯 rakeback (40%-80%)，专属客服 |

### Battle Pass 设计要素（GGPoker 为参考）

1. **赛季任务系统** — 每日/每周重置，驱动每日回访
2. **Token 化奖励** — 赛季积分可兑换专属头像/牌背/表情
3. **进度可视化** — 进度条、等级徽章、段位系统
4. **免费档** — 留存钩子，付费档解锁高价值奖励
