## 竞品调研 — 社交功能深度分析

> 本轮主题：**玩家社交生态 — Staking / 合桌 / 俱乐部**

### 核心发现

#### 1. GGPoker Stake Us（合股/代打）

| 功能 | 说明 |
|------|------|
| **Stake Us** | 玩家可为他人买入，赢取分成比例（up to 100%） |
| **Backer 可见被资助玩家手牌** | 实时观战并分析 |
| **收入分成自动化** | 平台直接结算，无需线下转账 |
| **支持多人合股** | 一手牌可有多名 Backer |

**产品价值:** 大幅降低新玩家门槛（无 bankroll 也能参与），同时创造 B2B 社交关系。

#### 2. GGPoker 私人俱乐部（Club）

| 功能 | 说明 |
|------|------|
| **私人邀请码入群** | 创建一个只有熟人的局 |
| **Club 专属 Rake 折扣** | 激励玩家留在平台 |
| **Club 排行榜** | 每周/每月竞争 |
| **Club 内部赛事** | 组织私人比赛 |

**产品价值:** 病毒式传播（邀请码机制）+ 玩家留存（专属感）。

#### 3. 888poker 特色 — 座椅抽签（Seat Shuffle）

- 比赛开始时随机分配座位，打破"老玩家霸桌"问题
- 增加游戏公平性感知，对新手友好

#### 4. CoinPoker — 加密社交

| 功能 | 说明 |
|------|------|
| **HUD 允许（宽松）** | 相比其他平台更开放 |
| **USDT 充值即时到账** | 链上透明，无 KYC |
| **聊天室加密货币打赏** | 边玩边打赏 |
