## 本轮产品调研 — 观战系统（Spectator Mode）

### 竞品现状

| 平台 | 观战功能 | 实现方式 |
|------|---------|---------|
| GGPoker | ✅ 完整观战 | 可看任意玩家手牌，观战列表，大师观战区 |
| WSOP (PlayStation) | ✅ 观战 | 朋友牌局观战，延迟观战 |
| 888poker | ❌ 无 | 仅好友邀请 |
| CoinPoker | ❌ 无 | 仅私密桌 |
| PokerStars | ✅ 观战 | 延迟5分钟，公众观战列表 |

### 观战系统核心功能（GGPoker 为标杆）

1. **观战列表** — 所有公开桌对所有玩家可见，可按盲注/类型筛选
2. **延迟观战** — 延迟5分钟，防止实时作弊（GGPoker/PokerStars 均采用）
3. **手牌可见性** — 观战者默认只看到公共牌，非当事人摊牌后才可见手牌
4. **观战者聊天** — 独立观战聊天室，与玩家隔离
5. **玩家视角切换** — 观战者可切换到任意玩家视角，看其手牌（观摩功能）
6. **观战统计** — 显示当前观战人数、牌桌状态

### 本项目现状

根据 AGENTS.md，本项目 **尚未实现观战系统**（P2-SOCIAL-001 待开发）。

### 观战系统使用场景

- **新手观摩** — 学习高手策略，观察不同级别的打法
- **好友互动** — 朋友在玩时实时观战（隐私保护下）
- **内容创作** — 直播/录播素材来源
- **社区运营** — 公众观战厅是留存的重要手段

### 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 公开桌观战列表 | 所有 `isPrivate=false` 房间对所有登录用户可见 | P2 |

| 观战者隔离 | 观战者不参与游戏操作，不可发言 | P2 |
| 观战人数显示 | 牌桌显示当前观战人数 | P3 |

### 数据库变更

```prisma
model Room {
  // 新增字段
  allowSpectators Boolean @default(true)  // 是否允许观战
  spectatorDelay Int @default(300)       // 观战延迟（秒），默认300（5分钟）
}
```

### WebSocket 事件

| 事件 | 方向 | 说明 |
|------|------|------|
| `spectator-join` | C→S | 观战者加入房间 |
| `spectator-leave` | C→S | 观战者离开 |
| `spectator-list` | S→C | 房间观战者列表 |
| `spectator-count` | S→C | 观战人数更新 |
| `game-state-spectator` | S→C | 延迟过滤后的牌桌状态（手牌信息按规则屏蔽） |

### 延迟观战实现方案

```
[游戏引擎]
    ↓ (实时)
[延迟队列 Redis Sorted Set]  ← score = timestamp + 300s
    ↓ (拉取延迟消息)
[观战网关]  ← 过滤手牌信息后转发
    ↓
[观战客户端]
```
