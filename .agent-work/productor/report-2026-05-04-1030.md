### P2-TOURNAMENT-GTD 规格建议（待确认）

```
GTD 机制规格书（草案）

1. 触发条件
   - 参赛人数 < N 时，平台补足到 GTD 金额
   - N = floor(GTD金额 / 买入) 或 固定值（如 10 人）

2. 资金来源
   - 选项A：平台风险基金（独立账户）
   - 选项B：赛事收入抽成（每手抽 1% 进入 GTD 池）
   - 选项C：混合（日常赛事平台承担，大赛赞助商承担）

3. 亏损上限
   - 建议：单场 GTD 最高平台承担 = GTD 金额 × 1.5
   - 超出部分：延期支付或降级为非 GTD

4. UI 展示
   - 赛事卡：GTD 橙色 Badge + "最低 X 人开赛"
   - 赛中：实时追踪已筹金额 vs GTD 目标
   - 赛后：GTD 达成/未达成提示

5. 结算流程
   - 赛事结束后，系统自动比对 totalPrize vs GTD
   - 差额由预设的 Platform GTD Wallet 账户自动转账
   - 管理员可手动审核大额 GTD 结算
```
