## 本轮调研主题: P2-TOURNAMENT-BLIND 深度分析

### 问题描述

P2-TOURNAMENT-BLIND：锦标赛盲注时间轴 UI — 需要在比赛详情页展示完整的盲注结构（级别/小盲/大盲/涨盲倒计时）。

### 当前代码现状

**已就绪的部分：**
- `ScheduleEntry` 类型包含 `smallBlind` 和 `clockIntervalSeconds` 字段
- `CountdownTimer` 组件（`/app/schedule/components/CountdownTimer.tsx`）— 通用倒计时组件，支持 D/H/M/S 显示，紧急状态（<5min）变红
- `TournamentCard` 展示基本信息（买入/人数/盲注/奖池）
- `/app/schedule/[id]/page.tsx` 详情页存在（未审查）

**缺失的部分：**
- 完整的盲注结构数组（`blindSchedule: BlindLevel[]`）在前端类型中未定义
- 详情页缺少**盲注时间轴可视化组件** — GGPoker 风格的水平进度条
- 当前 `ScheduleEntry` 只有 `smallBlind` 和 `clockIntervalSeconds`，没有完整的盲注级别列表

### 竞品参考（GGPoker 风格盲注时间轴）

```
Level 1   Level 2   Level 3   Level 4   Level 5
50/100    75/150    100/200   150/300   200/400
━━━━━━━━  ━━━━━━━━━━ ━━━━━━━━━ ━━━━━━━━━
↑ 当前级别（高亮 + 进度条）
颜色渐变：绿色 → 黄色（剩余 2 分钟）→ 红色（最后 30 秒）
```

### 建议实现方案

**前端数据模型扩展：**
```typescript
interface BlindLevel {
  level: number;
  smallBlind: number;
  bigBlind: number;
  durationSeconds: number; // 每级别持续时间
  ante?: number;           // 前注（可选）
}

interface TournamentDetail {
  // ... 现有字段
  blindSchedule: BlindLevel[];  // 完整的盲注结构
  currentBlindLevel: number;    // 当前级别索引
  levelStartTime: string;      // 本级别开始时间
  levelEndTime: string;        // 本级别结束时间（用于倒计时）
}
```

**UI 组件设计（BlindTimeline.tsx）：**
1. 水平滚动时间轴，显示所有级别
2. 当前级别高亮 + 进度条（已用时间 / 总时间）
3. 颜色编码：正常(绿) → 警告(黄 <2min) → 紧急(红 <30s)
4. 显示：级别号 / 小盲/大盲 / 剩余时间
5. Ante 显示（如有）
