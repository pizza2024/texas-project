## 本轮调研 — GTD 赛事深度分析

### GTD（Guaranteed Prize Pool）是什么
GTD 是德州扑克赛事的"保底奖池"——即使报名人数不足，平台也会补足到约定金额。这是主流平台（GGPoker/WSOP/888poker）的核心用户留存机制。

### 竞品 GTD 规格参考

| 平台 | GTD 最低档 | GTD 赛事频率 | 报名费/GTD 比 |
|------|-----------|-------------|--------------|
| GGPoker | $10 GTD 微型 | 每日数十场 | ~5-10% |
| WSOP | $100 GTD | 每日数场 | ~10-20% |
| 888poker | $50 GTD | 每日数场 | ~10% |
| **本项目（建议）** | $10/$50/$100 三档 | 每小时 1 场 | 待定 |

### GTD 资金来源方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| **方案 A：平台补贴** | 玩家感知价值高，早期吸引用户 | 平台承担亏损风险 |
| **方案 B：报名费池** | 0 风险，平台从 rake 盈利 | 初期吸引力低 |
| **方案 C：混合** | 最平衡，平台补差 + 玩家分摊 | 实现复杂度高 |

**建议：方案 A（平台补贴）+ 分级 GTD**
- $10 GTD（微型）：平台每日补贴 $5，报名费 $1
- $50 GTD（小）：平台每日补贴 $20，报名费 $5
- $100 GTD（中）：平台每日补贴 $50，报名费 $10
- 随用户规模增长，逐步过渡到方案 B

### P2-TOURNAMENT-GTD 规格草案

```
GTD 赛事配置字段：
- gtdAmount: number        // 保底金额（USD）
- gtdFundSource: 'PLATFORM' | 'BUYIN_POOL' | 'HYBRID'
- minRegistrations: number // 最低开赛人数（不足取消）
- maxRegistrations: number // 最高人数限制
- buyIn: number            // 报名费
- rakePercent: number       // 平台抽成 %
- startTime: Date
- schedule: BlindTimeline
```
