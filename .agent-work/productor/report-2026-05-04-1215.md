## 本轮竞品调研 — 移动端 UX 深度分析

### 调研对象
- **GGPoker** — 全球最大线上扑克平台，移动端行业标杆
- **WSOP (Caesars)** — 传统品牌，赛事为核心
- **ClubGG** — 私人俱乐部模式，对标我们的 P2-SOCIAL-002
- **CoinPoker** — 区块链扑克，币圈用户群

### 核心发现

#### 1. GGPoker 移动端 UX 优势

| 维度 | GGPoker 做法 | 我方参考 |
|------|-------------|---------|
| **牌桌布局** | 紧凑单页，所有操作在屏幕下半部，公共牌居中 | ✅ 我方 room-mobile 方向正确 |
| **操作效率** | 滑动条选择注码，1-click 全押/过牌 | ⚠️ 可优化：加滑竿而非纯数字输入 |
| **盲注提示** | 每个位置显示当前盲注额，大盲位高亮 | ✅ 我方已有 |
| **等待列表** | 实时显示预计等待时间，可后台排队 | 🆕 P2-SOCIAL-001 可借鉴 |
| **玩家信息** | Hover 显示 elo/最近战绩/国家旗 | ⚠️ 我方缺少快速玩家信息卡 |
| **动画流畅度** | 60fps 发牌/开牌动画，切牌无黑屏 | 技术债 |

#### 2. ClubGG 私人俱乐部模式（对标 P2-SOCIAL-002）

| 功能 | ClubGG | 我方规划 |
|------|--------|---------|
| 创建俱乐部 | 免费创建，生成邀请码 | ✅ 我方规格一致 |
| 俱乐部房间 | 房主定制盲注/准入/规则 | ✅ 我方规划 |
| 排行榜 | 俱乐部内 ELO 排名 | 🆕 待补充到规格 |
| 聊天 | 俱乐部私有聊天 + 牌局讨论 | ⚠️ 我方仅房间内聊天 |
| 视觉皮肤 | 可自定义俱乐部 LOGO/主题色 | 🆕 可扩展项 |

#### 3. 行业趋势 — 移动端扑克关键差异点

1. **一键操作优先级最高** — 成功牌手平均每手 < 3 秒决策，移动端必须滑竿 + 预设按钮
2. **社交层是留存核心** — GGPoker/ClubGG 均重度投入俱乐部/好友/观战，扑克是社交游戏
3. **赛事是第一获客入口** — WSOP 品牌效应，GTD 赛事是拉新主力
4. **移动端专用引擎** — GGPoker 有独立移动端渲染管线，不仅仅是响应式
