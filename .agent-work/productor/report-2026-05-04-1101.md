## 本轮调研 — 移动端德州扑克 UX 最佳实践

### 竞品移动端特性对比

| 平台 | 响应式布局 | 手势支持 | 投注按钮设计 | 充值体验 |
|------|-----------|---------|-------------|---------|
| WSOP | 固定 3D 桌面 | 滑动弃牌/跟注 | 底部滑动条 + 快速按钮 | IAP 为主 |
| 888poker | 自适应牌桌 | 滑动操作 | 筹码堆叠点击 | 银行卡 + 电子钱包 |
| GGPoker | 垂直重组布局 | 双击查看手牌 | Action bar + 快速 All-in | 加密货币原生 |
| CoinPoker | 移动端适配 | 基础手势 | 简化按钮 | USDT 直接充值 |

### 移动端 UX 关键发现

#### 1. 投注控件设计
- **底部 Action Bar**（GGPoker/WSOP 采用）：Fold / Check / Call / Raise 四按钮横排，高度 ≥ 48pt
- **滑动式下注条**：拇指易触及，支持精确值输入
- **快速金额按钮**：1/2 pot、All-in 常驻，减少输入摩擦
- **本项目差距**：当前 web 端 `/room/[id]` 为桌面设计，需确认 `/room-mobile/[id]` 覆盖完整性

#### 2. 手势交互
- **滑动弃牌**：左上/右上滑动，几乎所有主流 app 支持
- **双击手牌放大**：查看手牌详情（两张牌的放大展示）
- **长按玩家头像**：查看对手 ELO/战绩（隐私合规性需考虑）

#### 3. 充值/提现移动端
- **GGPoker**：加密货币原生 + 传统支付双通道，充值即时到账
- **CoinPoker**：USDT 充值 5-30 分钟确认，UI 流程极简（3 步完成）
- **本项目**：USDT 充值依赖 HD 钱包地址生成，轮询扫块确认，移动端地址展示/复制体验需优化

#### 4. 社交/观战
- **GGPoker 观战**：支持好友观战私密桌，延迟 30 秒防覗牌
- **WSOP 社交**：战队系统 + 成就徽章，提升留存
- **本项目**：P2-SOCIAL-001（观战）和 P2-SOCIAL-002（私人俱乐部）尚未进入开发阶段
