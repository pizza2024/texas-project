## 本轮竞品调研：All-In Insurance 完整规格

### 产品定义

All-In Insurance（又称 "All-In Protection"）是当玩家全下时，可选择购买的一种**亏损保护保险**。

### 触发条件

- 玩家执行 ALL-IN 操作
- 显示购买弹窗（倒计时内可取消）
- 玩家选择 50% 或 100% 保护档位

### 赔付算法

```
赔付金额 = 底池 × (1 - 玩家胜率) × 保护比例
```

例如：
- 底池 $100，玩家胜率 30%
- 100% 保护：赔付 = $100 × 0.7 × 100% = **$70**
- 50% 保护：赔付 = $100 × 0.7 × 50% = **$35**

### 数据库设计（建议）

```prisma
model Insurance {
  id          String   @id @default(uuid())
  handId      String
  userId      String
  buyinAmount Float    // 保险购买金额（从玩家筹码扣除）
  payoutAmount Float?  // 赔付金额（如玩家输掉此局）
  protection  Int      // 50 或 100
  status      InsuranceStatus // ACTIVE / CLAIMED / EXPIRED
  createdAt   DateTime @default(now())
}

enum InsuranceStatus {
  ACTIVE   // 已购买，等待结算
  CLAIMED  // 已赔付（玩家输）
  EXPIRED  // 未使用（玩家赢）
}
```

### WebSocket 事件设计

**服务器 → 客户端：**
```json
{ "event": "allin-insurance-offer", "data": {
  "handId": "uuid",
  "potSize": 100,
  "playerEquity": 0.3,
  "options": [
    { "protection": 50, "cost": 7, "payout": 35 },
    { "protection": 100, "cost": 14, "payout": 70 }
  ],
  "timeoutSeconds": 10
}}
```

**客户端 → 服务器：**
```json
{ "event": "buy-insurance", "data": {
  "handId": "uuid",
  "protection": 50 // 或 100
}}

{ "event": "decline-insurance", "data": {
  "handId": "uuid"
}}
```

## 本轮竞品调研：Bad Beat Jackpot 完整规格

### 产品定义

Bad Beat Jackpot 是**牌桌 jackpot 池**，当满足特定"坏牌"条件时分配给牌桌上输掉的玩家。

### 触发条件

| 条件 | 值 |
|------|----|
| 底池大小 | ≥ $100 |
| 输家手牌 | 77 或更高（口袋对子） |
| 赢家手牌 | AA / KK / QQ |
| 游戏阶段 | SHOWDOWN（摊牌） |

### 分配比例

| 对象 | 比例 | 说明 |
|------|------|------|
| 输家 | 50% | 被 bad beat 的倒霉玩家 |
| 赢家 | 25% | 赢下这个大底池 |
| 牌桌其他玩家 | 25% | 当局在场的所有玩家 |

### 数据库设计（建议）

```prisma
model BadBeatJackpot {
  id          String   @id @default(uuid())
  tableId     String
  handId      String
  loserHand   String  // "77" / "88" 等
  winnerHand  String  // "AA" / "KK" / "QQ"
  potSize     Float   // 触发时的底池大小
  jackpotPool Float   // 当前 jackpot 总额
  claimedAt   DateTime?
  status      JackpotStatus
  createdAt   DateTime @default(now())
}

enum JackpotStatus {
  PENDING_CLAIM
  DISTRIBUTED
  EXPIRED
}

model JackpotPool {
  id          String   @id @default(uuid())
  tableId     String   @unique // 每桌一个池
  amount      Float    @default(0)
  lastUpdated DateTime @updatedAt
}
```
