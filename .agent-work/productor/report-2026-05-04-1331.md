## 本轮竞品调研：Insurance & Jackpot 产品深度分析

### GGPoker — All-In Insurance

| 维度 | 详情 |
|------|------|
| **触发条件** | 玩家 all-in 后未亮牌前可购买 |
| **赔付计算** | 基于牌面 equity（胜率）计算赔付额 |
| **产品逻辑** | 玩家选择购买比例（0-100%），按 equity 折算赔付 |
| **UI 呈现** | all-in 后弹出保险面板，显示当前 equity / 建议购买额 |
| **差异化** | 可买部分保险（不全押） |

**产品价值：** 降低高波动场景的玩家损失厌恶，提升中低额玩家留存

### GGPoker — Bad Beat Jackpot

| 维度 | 详情 |
|------|------|
| **触发条件** | 特定底池大小以上，特定牌型（如 77+ 输给 AA） |
| **奖金分配** | 输家 50%，赢家 25%，其他玩家 25%（按牌桌占有度） |
| **累积机制** | 每次 Bad Beat 边池累积，Jackpot 公开显示金额 |
| **UI 呈现** | 大额 Jackpot 金额实时显示在牌桌顶部 |

**产品价值：** 制造话题性 High-Variance 体验，吸引休闲玩家
