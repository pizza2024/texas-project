### BlindTimeline 组件规格（草案）

**文件名:** `apps/web/app/schedule/components/BlindTimeline.tsx`

**Props:**
```typescript
interface BlindTimelineProps {
  blindSchedule: BlindLevel[];
  currentBlindLevel: number;     // 0-indexed
  levelStartTime: number;        // Date.now() at level start
  clockIntervalSeconds: number;  // 用于计算进度
  compact?: boolean;             // 移动端简化模式
}
```

**UI 设计（GGPoker 风格）：**

```
┌─────────────────────────────────────────────────────────────┐
│ L1  25/50    L2  50/100    L3  100/200   L4  200/400  →  │
│ ████████████░░░░  ░░░░░░░░░░  ░░░░░░░░░░  ░░░░░░░░░░░░  │
│            ↑ 当前（黄色高亮）                                 │
│            进度条 = (now - levelStartTime) / clockIntervalSeconds
└─────────────────────────────────────────────────────────────┘
```

**视觉规格：**
1. **横向滚动时间轴** — 所有级别从左到右排列
2. **当前级别** — 黄色/橙色高亮背景 + 内部进度条
3. **已过级别** — 绿色背景
4. **未到级别** — 暗色/半透明
5. **进度条** — 显示当前级别已用时间/总时间，颜色渐变（绿→黄→红）
6. **Ante 显示** — 如该级别有前注，显示在 sb/bb 下方
7. **移动端** — `compact=true` 时仅显示当前级别和相邻级别

**颜色编码：**
- 正常：`bg-green-900/50`
- 当前（活跃）：`bg-yellow-600` + 进度条
- 警告（<2分钟剩余）：`bg-orange-600`
- 紧急（<30秒）：`bg-red-600` + 闪烁
- 已完成：`bg-green-700`

**组件结构：**
```
BlindTimeline/
├── index.tsx              # 主组件
├── BlindLevelChip.tsx    # 单个级别的展示块
├── LevelProgressBar.tsx  # 当前级别进度条
└── types.ts              # 导出 props 类型
```
