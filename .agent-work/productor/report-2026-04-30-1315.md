## 竞品动态观察

### 本轮聚焦：赛事 GTD（Guaranteed Prize Pool）实现参考

GGPoker / WSOP 的 GTD 实现模式分析：

**GGPoker 赛事 GTD 机制：**
- 报名费 × 报名人数 = 实际奖池
- 实际奖池 < GTD 宣示值 → 平台补足差额
- Break 期间显示 GTD badge 持续强化用户预期
- 赛事结束后显示"平台额外补贴"强化品牌信任

**WSOP 赛事 GTD 机制：**
- GTD 在赛事名称中突出显示（如 "$1,000,000 GTD"）
- 实时显示当前奖池 vs 目标奖池进度条
- 达标/未达标在结算页明确告知用户

**本项目实现建议（P2-TOURNAMENT-GTD 规格参考）：**
```
GTD 触发条件：
  - 赛事创建时设置 gtDAmount 字段
  - 赛事结束结算时比较 (报名费 × 人数) vs gtDAmount
  - 差额由平台账户自动补足（admin wallet 或平台收入池）

UI 展示：
  - Timeline 上 GTD 级别用特殊颜色/图标区分
  - 赛事卡片显示 "Guaranteed $X" badge
  - 赛事结束显示 "+$Y added by platform"
```
